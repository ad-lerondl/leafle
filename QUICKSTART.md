# 🚀 Quick Start - Leafle

## Installation rapide (5 minutes)

### Prérequis
- Flutter SDK installé (^3.5.4)
- Un émulateur Android/iOS ou un appareil physique
- Git (optionnel)

### Étapes

```bash
# 1. Naviguer vers le dossier du projet
cd c:\DsqD\Programmation\Flutter\leafle

# 2. Installer les dépendances
flutter pub get

# 3. Vérifier qu'il n'y a pas d'erreurs
flutter analyze

# 4. Lancer l'application
flutter run
```

C'est tout ! 🎉

## 📱 Première utilisation

1. **L'app se lance** → Vous voyez l'écran d'accueil avec Leafle 🌱 et son embonpoint
2. **Appuyez sur "Routines"** → Liste des 8 routines prédéfinies
3. **Appuyez sur une routine** → Validez pour gagner des points ⭐
4. **Regardez Leafle** → Son énergie augmente automatiquement !
5. **Explorez "Dépendances"** → Ajoutez une anti-routine pour suivre une habitude à réduire
6. **Accumulez 100 points** → Plantez votre premier arbre moyen 🌳
7. **Notez votre journée** → Évaluez-la de 1 à 5 étoiles ⭐
8. **Revenez chaque jour** → Maintenez votre forêt en vie 🌲

## 🎮 Objectif du jeu

**Complétez vos routines → Réduisez vos dépendances → Nourrissez Leafle → Cultivez votre forêt !**

- Plus vous faites de routines = Plus Leafle a d'énergie
- Respectez vos anti-routines = Votre forêt est soignée
- Plus Leafle a d'énergie = Plus votre forêt est saine
- Négligez vos routines = Leafle s'affaiblit = Arbres meurent ☠️
- Dépassez vos limites = Votre forêt subit des dégâts
- Mode difficile actif = Pénalité si routine non faite

## 🎨 Personnalisation rapide

### Ajouter une routine :
1. Écran Routines → Bouton ➕
2. Choisissez icône, nom, description, points
3. Créer !

### Modifier le thème :
Éditez `lib/main.dart`, ligne 18-70

### Ajuster l'équilibrage :
Éditez `lib/providers/app_state.dart`
- Ligne 130 : coût arbre (actuellement 100)
- `lib/models/leafle.dart` ligne 41 : décroissance énergie

## 🌟 Conseil de départ

**Commencez simple !**
- Choisissez 3-4 routines réalistes
- Ajoutez 1-2 anti-routines pour suivre vos dépendances
- Plantez des arbres moyens au début (100 pts)
- Faites vos routines chaque jour pendant une semaine
- Observez Leafle et votre forêt prospérer
- Notez vos journées pour suivre votre bien-être
- Quand vous avez 30+ arbres, embauchez un mini-Leafle
- Organisez votre forêt en étages thématiques
- Utilisez le mode difficile avec parcimonie

**La régularité bat l'intensité !** 💪
